# Проверка на Windows

Проверка сборки uCAN Monitor для Windows с адаптером candleLight: от
подключения адаптера до обмена с устройством в программе. Займёт около
15 минут.

**Понадобится:**

- компьютер с 64-битной Windows 10 или 11, права администратора не нужны;
- адаптер candleLight;
- для шагов 4 и 5 — устройство на шине, 500 кбит/с, силовая часть выключена;
  на шине два терминатора по 120 Ом.

## 1. Скачать и распаковать

Один из вариантов:

- **с GitHub** (нужен вход в аккаунт GitHub): страница
  [Actions](https://github.com/alsizyakin/ucan-monitor-win/actions) →
  последний запуск *windows* с зелёной галочкой → внизу, в разделе
  *Artifacts*, архив `ucan-monitor-win-…`;
- **готовый архив** `ucan-monitor-win.zip` с флешки или из сети.

Распаковать в любую папку, например на рабочий стол. Внутри должны быть
папки `ucan-monitor\bin` и `ucan-monitor\assets`.

Программа не подписана, поэтому при первом запуске Windows может показать
«Windows защитил ваш компьютер»: *Подробнее* → *Выполнить в любом случае*.

## 2. Подключить адаптер

Вставить адаптер в USB. При первом подключении Windows сама ставит ему
драйвер (WinUSB), это до полуминуты. В *Диспетчере устройств* адаптер
появится как **candleLight USB to CAN adapter** в разделе *Устройства USB*,
без жёлтого значка.

## 3. Самопроверка адаптера (шина не нужна)

Открыть папку `ucan-monitor\bin` в Проводнике, в адресной строке набрать
`cmd` и нажать Enter. В открывшемся окне:

```
candle-test.exe -l >> check.txt 2>&1
candle-test.exe -m loopback -s 123#1122334455667788 -t 3 >> check.txt 2>&1
notepad check.txt
```

В самопроверке адаптер принимает собственные кадры, на шину ничего не идёт.

**Должно быть:**

- строка `candle0: 1d50:606f, …, candleLight USB to CAN adapter, serial …`;
- три строки `TX 123 [8] 11 22 33 44 55 66 77 88` и три такие же `RX`;
- в конце `Received 3 frames …, sent 3, send errors 0`.

Строки `ERR rx warning, tx warning` здесь не страшны: это счётчики ошибок
адаптера, оставшиеся от прошлых проверок.

## 4. Приём с шины

Подключить адаптер к шине с включённым устройством и в том же окне:

```
candle-test.exe -b 500000 -t 5 >> check.txt 2>&1
notepad check.txt
```

**Должно быть:** строки `RX` с кадрами устройства (`181`, `281`, `381`,
`202`, `203` каждые 100 мс, `701` раз в секунду), в конце около 290 принятых
кадров и ни одного кадра ошибок. В первые миллисекунды приходит пачка кадров,
которые устройство накопило, пока его никто не подтверждал, — так и должно быть.

Ключ `-s` здесь не использовать: он отправляет на шину произвольный кадр.

## 5. Программа

1. Закрыть окно `cmd`: адаптер может открыть только одна программа.
2. Запустить `ucan-monitor.exe` из `ucan-monitor\bin`.
3. Выбрать сервер устройства, *Ok*.
4. *Меню → Настройка*, вкладка *SocketCAN*: интерфейс `candle0`, битрейт
   `500000`, *Подключить*. Должно появиться «Успех!».
5. Убедиться, что значения в панелях устройства обновляются.
6. Закрыть программу и запустить снова: теперь она должна подключиться сама
   (в журнале строка `Restoring the CAN connection`).

После подключения программа шлёт свои обычные кадры, как и Linux-версия:
SYNC, heartbeat и команды панелей в исходном состоянии.

## 6. Что прислать

- `ucan-monitor\bin\check.txt` — вывод шагов 3 и 4;
- `ucan-monitor\bin\log.txt` — журнал программы после шага 5;
- снимок экрана, если что-то выглядит не так.

## Если что-то не так

| Признак | Что делать |
|---|---|
| `No candleLight adapters on USB.` | переподключить адаптер, попробовать другой порт USB, проверить *Диспетчер устройств* |
| в *Диспетчере устройств* жёлтый значок или нет драйвера; в `check.txt` `cannot open … NOT_SUPPORTED` или `NOT_FOUND` | поставить драйвер вручную: [Zadig](https://zadig.akeo.ie) → *Options → List All Devices* → *candleLight USB to CAN adapter* → *WinUSB* → *Install Driver* |
| `Access denied` | адаптер занят другой программой: закрыть её (в том числе второй `ucan-monitor` или `candle-test`) |
| `stuff error`, `form error` | у шины другая скорость: повторить шаг 4 с другим `-b` |
| программа не запускается, сообщение о недостающей DLL | прислать снимок экрана |
| «Ошибка. Код: N» при подключении | прислать `log.txt`: причина записана там |
